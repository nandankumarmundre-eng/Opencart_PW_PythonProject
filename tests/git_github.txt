Git & Github Work flow
------------
Git desktop (windows app) is a distributed version control to maintain the local repository in their own workspace.
Github - remote central repository to maintain the final project code.
---------------------------------------------
Git is a local repository
Github is a clould based remote repository
---------------------------------------------
Git is a desktop software, every individual has to download it and install in thier desktop and it should be part of your local repository.
------------------------------------------------------------------------------------------------------------------------------------------
A developer can add the workspace to git and make any changes or updates in the local repository and then they have to push to the Github.
we have to commit to the local repository and and push to the Github remote repository, this is daily job for a developer. 
------------------------------------------------------------------------------------------------------------------------------------------
Purpose - to maintain the different versions, to maintain local changes, and commit changes and push the changes to github remote repository.
whenever we need can pull/rollback the changes to local repository and update the files in the local git repository and again commit and push to the github remote repository.
